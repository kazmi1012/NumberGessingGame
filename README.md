

###  Number Guessing Game
- Computer picks a random number, player guesses
- Hints after each guess (too high / too low)
- Tracks number of attempts

## How to Run

1. Clone the repo
```bash
git clone https://github.com/kazmi1012/RockPaperScissors.git
```

2. Run any game
```bash
python numberguessing.py
```

- Python
- Random module
- Terminal I/O
